SPORTS GNM 3D PLAYER — INSTRUCCIONES PARA WINDOWS
=================================================

1. Descomprime el proyecto completo e instala Python si no lo tienes.
2. Ejecuta iniciar-servidor.bat.
3. Abre http://localhost:8080/ en un navegador con WebGL2.

No abras index.html con doble clic: el modelo 3D necesita descargar los
archivos locales mediante HTTP. No existe un renderer 2D alternativo.
Si WebGL2 o los archivos necesarios no están disponibles, se muestra un
error y se desactiva la exportación PNG.

index.module.html usa módulos para desarrollo; index.html usa el bundle.
Ambos muestran únicamente Sports GNM 3D Player v1.
